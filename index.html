// ¿Cómo participar?

Nivel 1 · Tester

Probá y reportá

  1. Abrí esta página en tu dispositivo
  2. ¿Algo se ve raro? ¿Algo no funciona?
  3. Abrí un Issue en el repo
  4. Describí lo que viste
Nivel 2 · Contribuidor

Agregá tu nombre

  1. Abrí contributors.json en GitHub
  2. Hacé clic en el lápiz ✏️
  3. Agregá tu entrada al final
  4. Abrí un Pull Request
Nivel 3 · Desarrollador

Mejorá el sitio

  1. git clone del repo
  2. Modificá index.html
  3. Creá una rama con tu feature
  4. Abrí un Pull Request
